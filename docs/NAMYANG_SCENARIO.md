# 현재 위치 → 현대자동차 남양연구소 경로

홈 화면과 ‘멀미 최소화 경로’ 상세 화면에서 **남양연구소로 안내 시작**을 누르면, Pleos 내비가 인식하는 현재 위치에서 남양연구소까지 실제 경로를 요청합니다.
기존 NaviHelper 3.0.5와 설치된 Pleos Navigation 앱을 사용합니다. 별도 지도 SDK나 API 키는 추가하지 않았습니다.

## 사용 순서

1. Pleos 내비 앱의 지도·위치·네트워크 연결을 확인합니다. 에뮬레이터 위치를 남양으로 바꿀 필요가 없습니다.
2. 정차 상태에서 SteadyRide의 **남양연구소로 안내 시작**을 누릅니다. 데모 모드에서는 시험차 신호 모드로 전환됩니다.
3. 실제 안내 상태와 남양연구소 목적지가 확인되면 내비에서 받은 거리·예상시간을 표시합니다.
4. **내비 화면 열기**로 지도를 확인하거나, 경로 상세 화면에서 기존 **멀미 적은 경로 탐색**을 실행합니다.

## 이전 버전과 달라진 점

- 목적지를 양재본사에서 **현대자동차 남양연구소**로 변경했습니다.
- 출발지를 남양 반경 2 km로 제한하던 검사를 제거했습니다. 기존 에뮬레이터 내비 위치에서도 요청할 수 있습니다.
- Android GPS를 조작하거나 출발 좌표를 주입하지 않습니다. `RouteInfo`에는 남양 목적지만 전달하고 출발 위치는 내비에 맡깁니다.
- 제목, 버튼, 진행·성공·오류 문구도 ‘현재 위치 → 남양연구소’로 변경했습니다.
- 기존 `tools/Set-NamyangLocation.ps1`은 이전 시나리오의 선택적 위치 설정 도구이며 이 기능에는 필요하지 않습니다.

## 동작 범위

- 목적지 이름: 현대자동차 남양연구소
- 주소: 경기도 화성시 남양읍 현대연구소로 150
- 지도 기준 좌표: 위도 `37.1552771`, 경도 `126.823083`. 공식 차량 출입구를 측량한 좌표가 아니므로 실제 방문 시 내비 도착 지점과 출입 안내를 확인해야 합니다.
- 현재 위치 값의 유효성 검사는 유지합니다. 위치를 받지 못하면 명시적으로 오류를 표시합니다. 유효한 출발 위치라도 내비 제공자의 지도·탐색 범위를 벗어나면 요청이 실패할 수 있습니다.
- 경로 요청 후 `isRouting`, 목적지 좌표(기준점 반경 500 m), 양수 거리·시간을 확인해야 성공으로 표시합니다. 기존 양재본사 안내 상태를 남양 안내 성공으로 처리하지 않습니다.
- 현재 위치 조회 5초, 서비스 연결 8초, 경로 확인 45초 제한을 둡니다. 실패 시 원인 또는 확인할 항목을 표시합니다.
- 연속 클릭, 경로 비교와의 동시 실행을 막고, 모드 전환·앱 종료 시 대기 작업을 취소합니다. 앱을 나가도 이미 내비에 전달된 경로를 자동 취소하지는 않습니다.
- 차량 주행 규제가 적용되면 시나리오 설정 버튼을 잠급니다.
- 이 기능은 경로 설정입니다. 자동 모의주행·속도 생성 기능은 추가하지 않았습니다. 회전 안내가 진행되려면 내비 위치가 이동해야 합니다.
- 실제 회전 정보는 기존 `LiveVehicleSource` → `ComfortEngine` → 화면·소리 흐름으로 전달됩니다. 동승자 감지 등 기존 케어 조건은 유지합니다.

## 수정 위치

- `core/NamyangScenario.kt`: 남양 목적지, 현재 위치 확인, 경로 확인 및 상태 메시지
- `ui/MainScreen.kt`: 제목·버튼·결과 표시
- `tests/ScenarioPolicyCheck.kt`: 기존 Pleos 위치에서 요청, 출발 지역 제한 없음, 잘못된 위치·목적지·거리·시간, 취소 검증
- `vehicle/ScenarioNaviGateway.kt`: 기존 어댑터가 새 목적지 상수를 사용합니다.

## 검증 방법

일반 개발 환경에서 다음과 같이 빌드·설치한 뒤 실제 SDK를 확인할 수 있습니다.

```powershell
.\gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest
adb install -r app\build\outputs\apk\debug\app-debug.apk
adb install -r app\build\outputs\apk\androidTest\debug\app-debug-androidTest.apk
adb shell am instrument -w -e expected READY ai.steadyride.app.test/ai.steadyride.app.ScenarioProbe
```

이 검사는 실제 내비 목적지를 남양연구소로 설정합니다. 현재 위치를 변경하지 않습니다.

## 이번 수정본 검증 결과

- 전체 Kotlin/Compose 소스 및 Android 검사 코드를 컴파일했습니다.
- 기존 Pleos 현재 위치에서 요청, 출발 지역 제한 제거, 잘못된 좌표·이전 양재 목적지·거리·시간·취소에 대한 정책 검사가 통과했습니다.
- 실제 Pleos 내비 화면에서 목적지가 현대자동차 남양연구소로 변경되고 약 61 km·53분 경로가 표시되는 것을 확인했습니다.
- 앱의 READY 확인 검사는 SDK 응답 대기 시간 초과로 통과하지 못했습니다. 내비에서 경로가 생성되더라도 앱 결과 표시는 시간 초과 오류가 될 수 있습니다.
- 일반 Gradle 빌드는 실행 환경의 프로젝트 디렉터리 접근 검사에서 실패했습니다. APK는 실제 Kotlin 컴파일 결과, 기존 프로젝트의 실행 의존성 DEX 및 리소스, Android SDK 도구를 사용해 조립·서명하고 에뮬레이터에 설치한 테스트용입니다.
- 경로 안내만 시작하며 위치 이동·자동 모의주행은 구현하지 않았습니다. P단·0 km/h에서는 지도상의 현재 위치가 자동으로 진행하지 않습니다.
- GitHub 원격 저장소에는 이번 변경을 업로드하지 못했습니다. Android Studio 원본 프로젝트는 별도로 적용해야 합니다.
